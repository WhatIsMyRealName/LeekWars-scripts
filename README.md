# Python scripts for LeekWars
## DISCLAIMER
This repository provides scripts that call the LW API. The LW API enables you to perform any action that is possible on the website, since the front end is completely separated from the back end.
However, the [Leek Wars terms of use](https://leekwars.com/conditions) state that "You are prohibited from creating, using or disseminating programs/scripts/sites not developed by the Leek Wars team for the purpose of cheating, automating a task or obtaining information from other users."
It also states that "In the event of a violation of one or more of the rules set out in these Terms of Use, the Leek Wars team reserves the right to restrict, without prior warning and at its sole discretion, your access to the game."
For now, the LW team tolerates the use of scripts, including those that automate the start of battles, and there is even documentation on the API ([here](https://leekwars.com/help/api) and [here](https://leekwars.com/encyclopedia/fr/Documentation_sur_le_retour_des_API)). However, this may change at any time, as stated in the terms of use.

Currently, none of the scripts in this repository require authentication, meaning that even if they automate a few tasks, they are neither cheating nor farming. They are also useful for the whole community and are available on the [forum on the website](https://leekwars.com/forum/category-6/topic-10448/page-7#message-69207), where the LW team has not deleted them.

This is why I am publishing them here.
